This tutorial uses Innovate's **0.7 development API**. It predicts a Logistic
curve from supplied parameters and checks the result independently. Start with
the [development installation](/innovate/user-guide/installation/); an older
package from a registry may expose a different API.

## Learning outcomes

After running the example, you can pass a Polars table to Rust, interpret the
prediction column, confirm that input identifiers survive the native call, and
check that invalid time grids produce an error.

## Prerequisites

Use the repository checkout with Python **3.15.2**, Rust **1.99.1**, and the
locked environment installed. You need basic Python and dataframe familiarity.
The example uses three synthetic observations, requires no dataset download,
and performs no network request.

The time unit is arbitrary but must agree with the parameters. With time in
years, `k` has units of inverse years and `x0` is measured in years; `L` is
the asymptotic level in your chosen adoption units.

## Interpretation

The curve is `L / (1 + exp(-k * (t - x0)))`. At `t = x0 = 1`, its level is
exactly half of `L = 100`, hence the central prediction of 50. The other two
values lie symmetrically around it. These are **levels**, not incident adoptions
per time step. The independent analytic expression belongs to the example's
test oracle; Innovate's scientific execution remains in Rust.

The input frame keeps its identifiers and ordering. A LazyFrame is collected at
the native boundary. Arrow IPC currently copies buffers, so the example makes
no claim of zero-copy transport.

## Limitations

This example supplies parameters; it does not estimate them from observations,
select a model, establish causal effects or calibrate predictive intervals.
A numerical identity on three synthetic points does not validate the Logistic
model for a real population. Time must be finite and strictly increasing.
Passing this tutorial does not close the wider scientific migration ledger.

Continue with the [current Python API](/innovate/api/python/) and the
[native scientific conventions](/innovate/native-migration/). The
[documentation quality contract](/innovate/maintainers/documentation-quality/)
explains what execution evidence does and does not establish.

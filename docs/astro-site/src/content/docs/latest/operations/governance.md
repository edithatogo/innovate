# External Governance and Sustainability

This page records support policy, funding posture, maintainer responsibilities, and external-facing governance readiness.

The dossier maps evidence status and remaining gaps for:

* maintainer roles and onboarding,
* security and citation policy,
* contributor workflow and communication,
* support and funding statements.

The canonical matrix is
`docs/source/_static/external_governance_sustainability_matrix.json`.
No external submission claim should rely on implied governance; the dossier
must cite explicit files and state remaining gaps.

## Governance evidence

* Maintainer roles: `CODEOWNERS`, `conductor/tracks.md`, and this dossier.
* Security policy: `SECURITY.md` and `CODE_OF_CONDUCT.md`.
* Citation metadata: `CITATION.cff`, `README.md`, and manuscript sources.
* Contributor onboarding: `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, and docs navigation.
* Support policy: release policy docs, roadmap ownership pages, and the support matrix.
* Funding path: community-maintained funding statement and roadmap references.
* Roadmap ownership: scientific/HPC roadmap, architecture modernization roadmap, and Conductor archive.
* Roadmap evidence includes the former `scientific_hpc_readiness_roadmap` contract,
  now maintained in the Astro scientific/HPC page.
* Roadmap references include `architecture_modernization_roadmap`.

## Support matrix

Python core is owned by core maintainers. R, Julia, Rust, TypeScript, Go, and
C# surfaces are owned by their binding maintainers. `innovate` is currently
community maintained and does not claim a dedicated sponsor or fiscal host.
Foundation outreach is governance-led, not marketing-led.

# Polyglot Registry Plan

The polyglot registry plan splits submissions by layer:

* package-manager registries,
* scientific-community submissions,
* HPC registry paths.

The sequence is intentionally conservative: evidence and readiness are tracked as independent lanes so proof and timing do not collapse into one milestone.

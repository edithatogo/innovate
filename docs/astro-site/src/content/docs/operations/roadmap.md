# Roadmap

The Rust core roadmap turns the contract-first architecture into an execution
plan.

Current migration posture:

- Python remains the reference ergonomic surface.
- Rust is the strategic long-term runtime for promoted execution slices.
- Bridge-backed slices remain explicit until they are either promoted or
  intentionally left on the Python side.

The roadmap should stay aligned with the archived Rust migration evidence and
the route inventory that preserves the current docs structure.

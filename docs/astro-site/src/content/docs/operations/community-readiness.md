# Community Submission Readiness

This page maps evidence readiness for scientific targets and ties each target to repository artifacts.

Covered communities include pyOpenSci, rOpenSci, JOSS, NumFOCUS, Apache Arrow, Julia and R communities, .NET Foundation, and Julia General.

No submission claim is accepted without explicit evidence and explicit gap status.

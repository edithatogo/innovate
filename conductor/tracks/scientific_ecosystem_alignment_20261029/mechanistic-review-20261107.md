# Mechanistic forcing review

Bass and Gompertz now support declared forcing, a continuous state across a
single event, conditional fitting and fixed-origin replay. The independent
SciPy DOP853 fixture checks held-out Bass values. Historical origin and
coefficient layouts are explicit. JSON float replay, signed-zero lookup and
R singleton arrays have regression evidence.

This is bounded local qualification. Multiple events, other model forcing,
weighted conditional fitting, stiff solver parity and hosted release remain open.

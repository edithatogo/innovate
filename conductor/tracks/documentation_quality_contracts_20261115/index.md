This track qualifies the existing Astro/Starlight implementation against the
current Rust and Polars development API. Archived migration records remain
historical evidence; they do not establish current content or publication quality.

The 16 November implementation delivers an optional native marimo notebook, a
frozen public-data fitting lesson, four focused advanced lessons, source-derived
Astro model/tutorial catalogues, stronger language documentation contracts, and
checked retirement of obsolete content. The current inventory has 14 tutorial
pages, 11 distinct canonical examples and 16 model discovery records. These are
different denominators: catalogue presence does not establish full model teaching
or scientific qualification.

The linked implementation record identifies executed checks and remaining work.
DOC-01–08 and the overall track remain in progress: additional empirical sources,
model chapters, installed R/Julia pathways, human reader evaluation and verified
publication are unfinished. This extends the existing ownership route. PR #656's
proposed archive move must preserve these obligations in an active, registered
documentation track or successor before integration.
